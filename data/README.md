# data/

| 폴더 | 용도 |
|------|------|
| `raw/` | 수집한 **원본** 데이터 (수정 금지). git 에는 올리지 않음 |
| `processed/` | 정제·병합 완료된 학습용 데이터. git 에는 올리지 않음 |

> 실제 csv 파일은 용량·저작권 문제로 git 에 커밋하지 않는다(.gitignore 참고).
> 수집 방법은 `src/collect_tourapi.py`, `src/collect_weather.py` 참고.

## 데이터 소스 요약

| 데이터 | 출처 | 비고 |
|--------|------|------|
| 축제/행사 정보 | 한국관광공사 TourAPI (`searchFestival`) | **필수 API** |
| 지역/시기별 방문자 수 | 관광 데이터랩 (datalab.visitkorea.or.kr) | 예측 타깃(y) — 수동 다운로드 |
| 날씨 (기온·강수) | 기상청 ASOS 일자료 | 핵심 피처 |
| 날씨↔방문 영향 계수 | 관련 논문/선행연구 | 파생변수 근거 |
