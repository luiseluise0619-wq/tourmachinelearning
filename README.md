# 🎪 축제 흥행 예보 (FestCast)

> 관광데이터 기반 축제 수요 예측 서비스
> 2026 관광데이터 활용 공모전(웹·앱 구현 부문) · 지정과제 9번

축제 기획안을 넣으면 **날씨·과거 데이터 기반 AI가 예상 방문자수와 흥행도를 '예보'** 하고,
예산 낭비를 막을 기획 보완 피드백을 주는 **지자체 실무자용** 서비스입니다.

## 🎯 과제 9 — 해결할 문제

> 축제 수요 예측 실패 및 주관적 경험 의존형 기획으로 인한 예산 낭비 리스크,
> 대규모 관광객 쏠림에 따른 축제 만족도 저하

- **타깃**: 축제 예산 집행 전 기획안의 객관적 검증이 필요한 지자체·축제 위탁사 실무자
- **필수 기능(예시)**
  - 개최 축제 개요 및 프로그램 세부 계획 입력
  - 데이터 기반 축제 흥행도 도출 + 기획 보완 피드백 리포트
- **해시태그**: `#축제/행사 기획` `#사전 수요 예측` `#보완 피드백` `#데이터 기반`

## 💡 우리 서비스 (핵심 차별점)

- **서비스명**: FestCast (축제 흥행예보관) — ※ 최종 확정 예정
- **핵심 아이디어**: 날씨가 축제 방문자수에 미치는 영향을 데이터·논문으로 정량화하여,
  기획안(일정·장소·프로그램)과 결합해 예상 방문자수·흥행도를 예측한다.
- **왜 뾰족한가**: 대부분 "감(感) 기획"인 축제를, 날씨 변수까지 반영한 객관적 예보로 바꿔
  예산 낭비와 쏠림을 예방.

### 🏆 대상 목표 확장판 — "예측기"에서 "기획 컨설턴트"로

예측만으로는 우수상까지가 한계. FestCast는 **예측 + 진단 + 처방 + 마케팅**까지 준다:

1. **예측** — 예상 방문자수 · 흥행도 점수(0~100)
2. **진단** — 날씨·수요·프로그램·시기 요인별 강·약점 분해
3. **처방(what-if)** — "일정을 성수기로 옮기면 +N점", "우천 대비 실내공간 확보" 등 구체 보완안
4. **마케팅** — 주변 지역 **연령대·성별 인구**를 근거로 타깃 세그먼트 → 홍보 채널 → 프로그램 추천
5. **내국인/외국인 분리 예보** — 특히 **K콘텐츠 연계 시 외국인 방문 증가분**을 정량화
   (주최 = 한국관광공사의 방한 외국인 유치 미션 정조준)
6. **확률 예보 + 쏠림 위험** — 방문자수를 "100명 단위 확률분포"로 예보하고,
   수용인원 초과 확률까지 산출 (과제 9의 "관광객 쏠림·만족도 저하" 직접 대응)

> 상세 설계: [`docs/architecture.md`](docs/architecture.md)
> 핵심 엔진: [`src/scoring.py`](src/scoring.py) — `python -m src.scoring` 로 샘플 리포트 즉시 확인

## 🗂 데이터 소스

| 데이터 | 출처 | 용도 |
|--------|------|------|
| 축제/행사 정보 | 한국관광공사 TourAPI **(필수)** | 축제명·일정·장소 |
| 지역/시기별 방문자 수 | 관광 데이터랩 (datalab.visitkorea.or.kr) | 예측 타깃(y) |
| 날씨 (기온·강수 등) | 기상청 API / 공공데이터포털 | 핵심 피처 |
| **주변 지역 연령대·성별 인구** | 주민등록 인구통계 (공공데이터포털) | **수요 베이스라인 + 마케팅 타깃** |
| **방한 외국인 관광 통계** | 한국관광공사 (방한 외래관광객 / TourAPI 외국어 정보) | **외국인 방문 예측 + K콘텐츠 효과** |
| 날씨↔방문 영향 계수 | 관련 논문/선행연구 | 파생변수·가중치 |

> ⚠️ 가장 오래 걸리는 단계 = **데이터 수집·정합**. 제일 먼저·꾸준히.

## 📁 폴더 구조

```
tourmachinelearning/
├─ README.md            ← 이 파일
├─ requirements.txt     ← Python 의존성
├─ .env.example         ← API 키 환경변수 템플릿
├─ data/                ← 수집한 원본·정제 데이터 (csv)
│   ├─ raw/             ← 원본 (수정 금지)
│   └─ processed/       ← 정제 완료 데이터
├─ notebooks/           ← EDA·모델링 주피터 노트북
│   ├─ 00_practice_heart.ipynb
│   ├─ 01_eda.ipynb
│   ├─ 02_features.ipynb
│   └─ 03_model.ipynb
├─ src/                 ← 데이터 수집·전처리 + 핵심 엔진
│   ├─ config.py        ← 설정·경로·API 키 로딩
│   ├─ collect_tourapi.py    ← TourAPI 축제 정보 수집
│   ├─ collect_weather.py    ← 기상청 날씨 수집
│   ├─ collect_population.py ← 주변 지역 연령대별 인구 수집
│   ├─ preprocess.py    ← 정합·청소·파생변수
│   └─ scoring.py       ← ⭐ 흥행도 점수 + 보완 피드백 + 마케팅 추천 엔진
├─ web/                 ← 웹/앱 프론트 + 배포
└─ docs/                ← 기획서·기능설명서·발표자료
    └─ architecture.md  ← 서비스 아키텍처 (대상 목표 확장판)
```
