## 권장 실행

1. **지금**: A세트(✅)로 모델·데모 운영 — 이미 R²≈0.55.
2. **다음(키 발급)**: B세트를 `enrich`·수집기로 결합 → 재학습, R² 상승 목표.
   특히 **날씨 + 소셜 관심도**가 가장 큰 상승 기대(방문 직접 변수·선행지표).
3. **여유되면**: C세트에서 쉬운 것(지정등급·연휴·환율)부터.

> "변수를 줄인다"의 정답: **다 수집하되, 학습엔 A + B의 유의미한 것만** 투입
> (시점정합 통과 + p값/중요도 상위). 나머지는 성능 기여 확인 후 추가.
> ML은 강력하지만 **고신호 데이터 > 많은 변수** — 쓰레기 넣으면 쓰레기 나온다.
