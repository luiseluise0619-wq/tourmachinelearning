## 결론 — 모델에 넣을 변수 (근거 확정)

**1순위 (강한 데이터 근거, p<0.01)**: 예산 · 지역 · 기간 · 회차 · 유형 · 운영주체(민간여부)
**2순위 (유의, p<0.05)**: 개최주기(매년)
**보류 (비유의, 추가 데이터 필요)**: 정부지원 · 재단운영 · 실내외 등

→ 이 1·2순위가 **"데이터상 영향 가장 큰 변수"** = 회귀/피드백의 근거 기반.
→ 남은 R²(약 45%)는 **미수집 변수**(날씨·주변인구·K콘텐츠·홍보·경쟁) 몫
  → 이들을 T2/조인으로 붙이면 예측력 상승 (추가 수집의 근거).

## 주의 (정직한 한계)

- 예산↔방문객은 **양방향**(큰 축제라 예산 크고, 예산 커서 방문 큼) → 인과로 단정 금지, 규모 대리지표로 사용.
- y는 **전년 방문객**(단년 횡단면) → 다년 시계열 확보 시 성장추세·시점정합 강화 가능.
- 방문객 실측(measured)은 453건뿐 → 학습 시 실측 가중.
