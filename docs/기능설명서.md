## 0. 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | **FestCast (축제 흥행 예보 서비스)** |
| 타깃 | 축제 예산 집행 전 기획안의 객관적 검증이 필요한 **지자체·축제 위탁사 실무자** |
| 주제 | 축제 기획안을 입력하면 **사전 흥행 가능성을 예측·진단하고 개선점을 제안**하는 예보 서비스 |
| 한 줄 | "감(感)으로 예산 3억 쓰던 축제를, **데이터 근거로 사전 검증**한다" |

**데이터**: 문화체육관광부 2026 전국지역축제 **1,266건 실측**(방문객·예산·회차) 학습 +
한국관광공사 TourAPI · 기상청 · 공공데이터포털 연동(예정).

**데모(동작)**: `web/demo.html` — 기획안 입력 시 리포트가 실시간 산출.

## 기능 ① `#축제/행사 기획` — 기획안 입력

**설명**: 개최 축제의 개요와 프로그램 세부 계획을 입력받는다.

| 입력 항목 | 예시 |
|-----------|------|
| 개요 | 축제명 · 지역 · 개최 월 · 기간(일) · 실내/실외 · 주말·연휴 여부 |
| 규모 | 예산(백만원) · 개최 회차 · 운영 주체(재단/지자체/민간) |
| 프로그램 | 체험 · 먹거리 · 공연 · 셀럽 라인업 · 입장료 무료 여부 |
| 글로벌 | K콘텐츠 연계 여부 |
| 안전 | 수용인원(쏠림 위험 산출용) |

- **구현**: 입력 스키마 `FestivalPlan`/`RegionContext`/`MacroContext` (`src/scoring.py`),
  실측 축제→입력 매퍼 `src/festival_to_plan.py`.
- **데모 화면**: 좌측 입력 패널 · **실제 축제 프리셋 버튼**(보령머드축제 등)으로 즉시 로드.
- **산출물 캡처 위치**: 데모 좌측 폼 전체.

## 기능 ② `#사전 수요 예측` — 흥행도·방문자 예보

**설명**: 입력된 기획안으로 예상 방문자수와 흥행도를 예보한다. 단일 숫자가 아니라
**확률분포**로, 내국인/외국인을 분리해 산출한다.

| 출력 | 내용 |
|------|------|
| 흥행도 점수 | 0~100 + 등급(A~D). **5개 요인**(날씨·수요·프로그램·시기·평판) 가중합 |
| 예상 방문자 | 총계 + **내국인/외국인 분리** |
| 확률 예보 | **100명 단위 확률분포** + 80% 신뢰구간 (몬테카를로 3천회) |
| 쏠림 위험 | 수용인원 초과 확률 → **과제 9 후반부("관광객 쏠림·만족도 저하") 직접 대응** |
| K콘텐츠 효과 | 연계 시 외국인 방문 증가분 정량화(방한 외국인 유치) |

- **구현**: `appeal_score()`·`estimate_visitor_split()`·`forecast_distribution()` (`src/scoring.py`).
  재개최 축제는 **전년 실측을 앵커**로 예측.
- **검증**: 보령머드축제 예측 **179만 vs 실측 169만** (오차 6%, 80% 구간 내).
- **데모 화면**: 우측 상단 흥행도 게이지 + 방문자 + 확률분포 히스토그램 + 쏠림 위험.

## 기능 ③ `#보완 피드백 제공` — 기획 개선 리포트

**설명**: 약한 요인마다 **"이렇게 바꾸면 어떻게 좋아지는지"(what-if)** 구체 처방을 생성한다.

| 진단 항목(예) | 처방 |
|---------------|------|
| 날씨 리스크 | 우천 대비 실내 대체공간·천막 확보 (+예상 점수) |
| 평일 개최 | 주말·공휴일 포함 일정으로 조정 (+예상 점수) |
| 연휴 미활용 | 인접 공휴일·징검다리 연휴에 배치 |
| 프로그램 빈약 | 부족 요소(체험/먹거리/공연) 우선 보강 |
| 외국인 유치 기회 | K콘텐츠 연계 + 다국어 홍보 (외국인 N명 추가 기대) |
| 마케팅 | 주변 인구 기반 타깃 세그먼트·홍보 채널·프로그램 추천 |

- **구현**: `generate_feedback()`·`recommend_marketing()` (`src/scoring.py`) — 총 13종 규칙.
- **데모 화면**: 우측 하단 "기획 보완 피드백" 카드 + "마케팅 추천".
- 입력을 바꾸면 피드백이 **실시간 갱신**되어, 실무자가 개선안을 즉석에서 비교 가능.

## 기능 ④ `#데이터 기반` — 예측의 근거

**설명**: 모든 예측·처방을 **실측 데이터와 통계적 근거**로 뒷받침한다. (감/주관 배제)

| 근거 | 내용 |
|------|------|
| 데이터 | 문체부 전국축제 1,266건(방문객·예산·회차·내외국인 실측) |
| 회귀 근거 | 각 변수의 계수·95% CI·**p값** (예: 예산 10배당 +327% p<0.001, 기간 +1.9%/일) |
| 예측력 | GBM 교차검증 **R²=0.55** |
| 근거 체계 | T1 데이터학습 / T2 문헌·통계 / T3 규칙+민감도 (`docs/evidence_framework.md`) |

- **구현**: `src/load_festivals.py`(로더) · `src/model.py`(회귀·유의성) · `src/eda.py`(영향 분석).
- **데모 화면**: 흥행 요인 옆 "데이터 근거" 접이식 패널(계수·유의성 표) + 요인명 마우스오버 툴팁.
- **분석 자료**: `docs/model_evidence.md`, `docs/methodology_report.html`(방법론 리포트).

## 기대 효과

- **예산 낭비 방지**: 집행 전 흥행도·방문자를 근거로 검증 → 실패 리스크 사전 차단.
- **쏠림·안전**: 수용 초과 확률로 안전 인력·동선 사전 계획.
- **외국인 유치**: K콘텐츠 연계 효과 정량화 → 방한 관광 활성화(관광공사 미션).

> ※ 본 문서는 초안. 1차 심사 제출 시 각 기능별 **데모 화면 캡처**를 첨부해 완성한다.
